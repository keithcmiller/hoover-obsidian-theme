## [1.0.0] — 2026-04-24

### Added
- Initial release
- Light mode: Hoover Cream background, Hoover Slate text
- Dark mode: Hoover Slate background, Hoover Cream text
- Primary color palette: Hoover Green (`#31C576`), Slate (`#283A40`), Cream (`#F0E9DD`)
- Full secondary palette: Black, Dark Green, Mint, White
- Division accent switching:
  - `hoover-twp` class → Hoover Orange (`#FF6C13`) for Treated Wood Products
  - `hoover-has` class → Hoover Blue (`#1BA0F5`) for Architectural Solutions
- Division callout blocks (`[!twp]`, `[!has]`) with auto-labels
- N27 headline font with Acumin Pro body fallback
- Heading color system (H2 = accent, H3 = dark green)
- Branded table headers (accent background, uppercase, N27 font)
- Branded blockquotes with accent left border
- Branded horizontal rule with green stripe pattern
- Branded code block left border
- Style Settings plugin support with division selector dropdown
- Per-note `cssclasses` support (`hoover-twp`, `hoover-has`)
- Print/PDF export fixes for dark mode
- `.hide-properties` class toggle for reading mode
- `.hoover-hdcl` toggle for colored H1–H6 headers
- `.hoover-hi-line` toggle for active line highlighting
- `.hoover-boxed-tags` toggle for bordered tag pills
- `.hoover-rm-status` toggle to hide the status bar
